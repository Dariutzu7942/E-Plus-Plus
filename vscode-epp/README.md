# E++ Language Support

This small VS Code extension associates `.epp` files with the E++ language and contributes the E++ icon theme.

## Install in a Codespace

The repository includes a prebuilt VSIX. Install it with:

```sh
code --install-extension epp-language-support-0.1.0.vsix
```

The repository workspace selects the `E++ Icons` theme automatically. Reload the VS Code window if an open `.epp` file does not show the icon immediately.
